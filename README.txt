NEXORA V5 — ALL LANGUAGE QUIZ EDITION
1. Keep index.html, style.css and script.js in the same folder.
2. For GitHub Pages, upload all 3 files to the repository root.
3. Open index.html locally or use GitHub Pages.
4. Quiz topics included: Python, JavaScript, HTML, CSS, Java, C, C++, C#, Go, Rust, PHP, SQL, Swift, Kotlin, TypeScript, Ruby, R, Dart.
5. Each quiz gives score, percentage, grade and answer review, and saves history in localStorage.
6. The browser Code Lab runs HTML/CSS/JS. Native execution of C/C++/Java/Python/etc. needs a secure server-side compiler service; this static version does not pretend to compile those languages.
7. Real Google authentication and cloud sync require Firebase/Supabase or another backend.
